# خەرجییەکان (Expenses) - Household Budget & Wealth App

سیستەمێکی پێشکەوتووی بەڕێوەبردنی خەرجی و بودجەی خێزانی، پاشەکەوت، سەروەت، زێڕ، قەرز، و بازاڕ بە کوردی (سۆرانی و بادینی) و ٥ زمانی تر.

---

## 🌟 تایبەتمەندییە سەرەکییەکان (Features)

### ١. خەرجییەکان (Expenses)
- **خوێندنەوەی وەسڵ بە ژیریی دەستکرد (AI Receipt Scanner)**: کامێرا یان وێنەی وەسڵی عێراقی و هەرێمی کوردستان بخوێنەوە بە مۆدێلی نوێی Gemini 3.8 Flash؛ بڕی پارە، دراو (دینار/دۆلار)، کات، ناوی فرۆشیار و جۆری خەرجی بە شێوەی خودکار پڕدەکرێتەوە.
- **تۆمارکردنی خێرا (Natural Language Quick Entry)**: بە دەقی ئاسایی بنووسە، نموونە: «٤٥ هەزار نان و میوە» یان «25$ بەنزین»، ئەپەکە دەیکاتە خەرجی.
- **هاوپێچکردنی وێنەی وەسڵ**: پاراستنی وێنەی فاکتۆڕەکان.
- **چاودێریی لیمیت و بودجە**: ئاگادارکردنەوە پێش ئەوەی بودجە لە سنوور تێپەڕێت.
- **پێشبینیی کۆتایی مانگ و ڕێژەی ڕۆژانەی ماوە (Daily Allowance)**.
- **تۆماری خەرجییە دووبارەبووەوەکان (Recurring Expenses)** لەگەڵ دیاریکردنی ڕۆژی مانگ.
- **گەڕان، فلتەری ورد، دەستکاریکردن و گەڕاندنەوەی سڕاوە (Undo)**.

### ٢. ڕاپۆرتەکان (Reports)
- کلیلە سەرەکییە داراییەکان: داهات، خەرجی، پاشەکەوت، ئەوەی ماوەتەوە، ڕێژەی پاشەکەوت.
- **شیکاریی دۆنەتی جوڵاو (Animated Donut Chart)** بۆ جۆرەکانی خەرجی.
- **ڕێسای ٥٠/٣٠/٢٠ (50/30/20 Rule)**: پێداویستییە سەرەکییەکان، حەز و ئارەزووەکان، پاشەکەوت.
- **خەرجی بە پێی ئەندامانی خێزان**.
- **بەراوردی ١٢ مانگی ساڵ** (داهات بەرامبەر خەرجی).
- **خشتەی بودجەی مانگانە**: پێشنیارکردنی خودکاری بودجە لە تێکڕای ٣ مانگی پێشوو (+٥٪ یەدەگ).
- **بەراوردی دوو مانگ**: جیاوازی و گۆڕانکاریی ڕێژەیی لە نێوان مانگەکانی ساڵ.
- **تەسوویەی نێوان ئەندامانی خێزان (Household Member Settle-Up)** بۆ خەرجییە هاوبەشەکان (کێ قەرزارە بە کێ).
- **١٠ گەورەترین خەرجییەکانی مانگ**.
- **ڕاوێژکاری دارایی مانگانە بە ژیریی دەستکرد (AI Monthly Budget Coach)**.
- **دەرکردن بۆ ئێکسڵ (Excel XLSX via SheetJS)** و چاپکردن (Print/PDF).

### ٣. پاشەکەوت (Savings)
- ئامانجەکانی پاشەکەوت بە بڕی دیاریکراو و مانگی مەبەست.
- هەژمارکردنی خودکاری بڕی پێویستی مانگانە بۆ گەیشتن بە ئامانج.
- تۆماری دانانی پارە لەم مانگەدا بە توانای پەشیمانبوونەوە (Undo).

### ٤. سەروەت و سامانی خێزان (Wealth & Net Worth)
- **نمرەی تەندروستیی دارایی (Financial Health Score 0-100)** بە پێی یاساکانی بەڕێوەبردنی سەروەت.
- **تۆماری سەروەتی زێڕ (Gold Wealth Ledger)**: کێش بە گرام، عەیاری ٢٤، ٢٢، ٢١، ١٨، بەهای کڕین، بەهای بازاڕیی ئێستا بە پێی نرخی عەیار ٢١ و قازانج/زەرەر.
- **قەرز و داواکارییەکان (Unified Debts List)**: قەرزم کردووە / قەرزم داوە، قیستی مانگانە، کاتی تەواوبوون، و تاقیکردنەوەی خێراتر تەواوبوون بە پارەی زیادەی مانگانە.
- **یەدەگی تەنگانە (Emergency Fund Runway)**: چەند مانگ خێزان دەتوانێت بە سامانی نەختینە بژی.
- **مەزەندەی زەکات (Zakat Estimate)**: نیصاب (٨٥ گرام زێڕی عەیار ٢١) و ڕێژەی ٢.٥٪ لەگەڵ ڕێنمایی شەرعی.

### ٥. لیستی بازاڕ (Shopping List)
- تۆمارکردنی کاڵاکان بە دانە و نرخی مەزەندەکراو.
- زیادکردنی کۆمەڵێک کاڵا پێکەوە (Bulk Add).
- گۆڕینی خودکاری کڕدراوەکان بۆ خەرجیی خواردن و بازاڕ (Grocery Expense).

### ٦. زیاتر (More Tools)
- **کۆمەڵەی پاشەکەوت (جەمعیە / Kumala)**: بەشداربووان، بڕی مانگانە، کۆی پارەکە (Pot)، نۆرەی وەرگرتن، تۆمارکردنی پارەدانی مانگانە (لە جۆری ٣٠) و وەرگرتنی پارەی کۆمەڵە (زیادبوون بۆ داهات).
- **پلانی بۆنە و جەژنەکان (Events Planner)**: جەژن، نەورۆز، زەماوەند بە بودجە، پێداویستییەکان و پاشەکەوتکردن.
- **خەرجیی ساڵانە (Sinking Funds)**: دابەشکردنی خەرجییە گەورەکانی ساڵ بەسەر ١٢ مانگدا.
- **بەروارە گرنگەکان (Important Dates)**: بیمە، ئیقامە، گەرەنتی و ساڵڕۆژ بە ئاگاداری ڕۆژ پێشتر.

### ٧. ڕێکخستن، پاراستن و زمان (Settings)
- **شاردنەوەی داهات و پاراستن بە پاسکۆد (PIN Protection)** بە هشکردنی SHA-256.
- کاتێک داهات شاردراوەتەوە، لە هەموو بەشەکان دەبێتە `••••••` و لە کاتی دەرکردنی ئێکسڵیش ناخرێتە ڕوو.
- **٦ زمان**: کوردی سۆرانی (بنەڕەت)، کوردی بادینی، عەرەبی، ئینگلیزی، فارسی، تورکی بە گۆڕینی ئاراستەی RTL و LTR.
- **پڕۆفایل و کارگەکانی تر (Workspaces)**: ماڵ، کار و کەسی سەربەخۆ.
- **کۆپیکردنی پارێزراوی تەواوی داتا (JSON Backup & Restore)** و **دەرکردنی CSV**.
- **دەستکاریکردنی ڕووکار**: ڕووناک، تاریک، سیستەم، ڕەنگی دڵخواز، فۆنتەکانی Noto Sans Arabic و Noto Naskh Arabic، قەبارەی دەق و گۆشەکان.

## 💻 تەکنەلۆژیا و دابەزاندن (Tech Stack)

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons
- **Backend / API**: Node.js, Express, @google/genai SDK (Gemini 3.8 Flash)
- **Excel Export**: SheetJS (xlsx)
- **Dev Server**: `npm run dev` (running port 3000 via server.ts + Vite middleware)

- گۆڕینی دراوی بیانی بە نرخی تۆمارکراو

- دابەشکردنی ٥٠/٣٠/٢٠
- هەژمارکردنی نمرەی تەندروستیی دارایی (Health Score 0-100)
- هەژمارکردنی زەکات و نیصاب بە پێی ٨٥ گرام زێڕ
- نرخی عەیارەکانی زێڕ بە پێی عەیاری ٢١
- تەسوویەی نێوان ئەندامانی خێزان
